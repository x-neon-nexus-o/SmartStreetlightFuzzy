# Project Report Outline

Use this outline to turn the working prototype into the final college report.

1. **Introduction:** motivation, problem statement, objectives, and scope.
2. **Literature review:** fixed-threshold lighting, adaptive lighting, and
   fuzzy-control applications.
3. **System analysis and design:** inputs, output, architecture, use cases,
   and data flow.
4. **Methodology:** fuzzification, membership curves, nine-rule base,
   Mamdani min/max inference, and centroid defuzzification.
5. **Implementation:** Python, NumPy, Streamlit, visualizations, and the
   simplified power model.
6. **Testing and results:** five scenarios, boundary tests, membership plots,
   traffic-response curve, and threshold comparison.
7. **Conclusion and future scope:** simulated-input limitation, vehicle
   detection, live sensors, multi-lamp simulation, and measured energy study.

Include screenshots from the running dashboard in `screenshots/` before
submission. Do not report an energy-saving percentage unless it is calculated
from a defined workload and baseline.
